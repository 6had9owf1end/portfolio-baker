# portfolio-baker

Кулінарний блог кондитера. Сайт-портфоліо з рецептами,
фото десертів та історією майстра.

## Автор
Бібко Олександр Сергійович, група СОІ-24-1

## Технології
- HTML5
- CSS3
- JavaScript

## Лабораторна робота № 5
Макетування сторінки за допомогою CSS Grid: створено сторінку дашборду [dashboard.html](dashboard.html) з адаптивною сіткою (.layout на grid-template-areas, картки на CSS Grid).

## Лабораторна робота № 6
Основи JavaScript: логіка та робота з даними. Створено сторінку [lab6.html](lab6.html) з конвертером величин маси та інтерактивним каталогом товарів кондитерської на [lab6.js](lab6.js).

## Лабораторна робота № 7
DOM та обробка подій: інтерактивний список задач. Створено застосунок [todo.html](todo.html) («Замовлення та заготовки кондитерської») із збереженням у localStorage (ключ lab7-todos-1), валідацією, вибором пріоритету та сортуванням.

## Лабораторна робота № 8
Робота з REST API через Fetch: пошук рецептів десертів та випічки через TheMealDB API ([api.html](api.html)). Реалізовано 4 стани інтерфейсу (loading, error, empty, success), таймаути та збереження «Обраного» у localStorage (ключ lab8-favorites-1).

## Лабораторна робота № 9
Основи React: компоненти та JSX. Створено застосунок [todo-react](todo-react/) (To-Do List для замовлень та заготовок кондитерської) на функціональних React-компонентах із передачею даних через props, умовним рендерингом, компонентом Badge та фільтрацією.

## Лабораторна робота № 10
React: стан, хуки та форми. Розширено застосунок [todo-react](todo-react/): реалізовано керування станом через useState та useEffect, контрольовану форму з валідацією, живий пошук і фільтрацію, завантаження з API та збереження в localStorage (ключ todos-lr10-1).
